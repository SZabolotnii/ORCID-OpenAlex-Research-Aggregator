## S5. Модель ручної праці ±50 %

Вхід: 6792 записи на ЗВО, 1390 рішень про дублікати, 20 кафедр. Базова оцінка — **413,8 год/рік**.

| Сценарій | Год/рік | Δ |
|---|---|---|
| базовий (a=2,5; b=5; c=45) | 413,8 | 0 % |
| a −50 % / +50 % | 272,3 / 555,3 | ∓34,2 % |
| b −50 % / +50 % | 355,9 / 471,8 | ∓14,0 % |
| c −50 % / +50 % | 406,3 / 421,3 | ∓1,8 % |
| усі −50 % / +50 % | 206,9 / 620,8 | ∓50 % |

**Що це доводить:** висновок стійкий за порядком величини — навіть за вдвічі оптимістичніших
припущень ідеться про **сотні годин** ручної роботи на рік. Домінує коефіцієнт `a` (час на запис),
тож саме він має бути першою ціллю хронометражу.

## Аналітичне обґрунтування порогів (для тексту статті)

Пороги у шкалі логарифмічних шансів: θ = 0,90 ⇔ β·φ = 2,197; θ = 0,70 ⇔ β·φ = 0,847.
Звідси зміст обраних значень читається прямо з ваг:

| Сценарій пари | β·φ | score | Рішення |
|---|---|---|---|
| збіг DOI, інші ознаки нульові | +3,000 | 0,953 | автозлиття |
| повний збіг усіх текстових ознак, без DOI | +4,100 | 0,984 | автозлиття |
| реалістичний збіг без DOI (назва 0,85; символи 0,75; рік; автори 0,6; журнал 0,4) | +2,920 | 0,949 | автозлиття |
| схожа назва без року й авторів (0,8 / 0,7) | +1,520 | 0,821 | смуга HITL |
| **конфлікт DOI + повний збіг усіх текстових ознак** | **−0,900** | **0,289** | **відкинуто** |

Останній рядок — ключовий: конфлікт DOI (−5,0) не долає навіть максимально можлива сума всіх
текстових свідчень (+4,1), тож пара з різними валідними DOI не досягає навіть смуги перевірки.
Це і є формальний вираз проєктного правила «жодного автоматичного злиття без сильного свідчення».

Додатково: вага `doiMatch` має **26,8 % запасу** до порога (2,197 із 3,0) — тому її збурення на
−25 % у S3 не змінює жодного рішення (ΔF1 = 0), що узгоджується з таблицею S3.

## Готові фрагменти для рукопису

### До «Методики», після формули трудомісткості (R2-1)

> Наведені коефіцієнти (a = 2,5 хв на запис; b = 5 хв на рішення про дублікат; c = 45 хв фіксованих
> витрат на звіт) є **експертними припущеннями, а не результатом хронометражного дослідження**.
> Тому отримані значення слід трактувати як базовий орієнтир порядку величини. Аналіз чутливості
> показує, що висновок стійкий: за варіації всіх коефіцієнтів у межах ±50 % оцінка змінюється в
> діапазоні 206,9–620,8 год/рік, тобто йдеться про сотні годин ручної роботи незалежно від
> конкретних припущень; домінує коефіцієнт a (34,2 % зміни на ±50 %). Пряме хронометражне
> підтвердження за участю працівників ЗВО заплановано як окремий етап дослідження.

### До «Методики», до або після табл. 1 (R2-2)

> Ваги β **не оптимізували на розміченому датасеті** — вони задані експертно як апріорні
> коефіцієнти логарифмічних шансів, що відображають відносну надійність свідчень (збіг DOI —
> найсильніше позитивне свідчення, конфлікт DOI — блокувальне негативне). Відповідно, коректно
> говорити про логістичну функцію оцінювання з експертно заданими вагами, а не про навчену
> логістичну регресію. Щоб показати, що результат не залежить від конкретних числових значень,
> проведено аналіз чутливості: збурення кожної ваги окремо на ±25 % змінює F1 щонайбільше на
> 0,65 п.п., а за одночасного випадкового збурення всіх ваг на ±25 % (20 векторів) F1 становить
> 76,06 ± 0,58 % проти 76,53 % для опублікованих значень. Донавчання ваг на розміченій вибірці
> реального ЗВО є напрямом подальшої роботи.

### До «Методики», після опису кроку 3 (R2-3)

> Обидва пороги мають прозорий зміст у шкалі логарифмічних шансів: θ_match = 0,90 відповідає
> β·φ = 2,197, θ_review = 0,70 — β·φ = 0,847. Звідси випливає проєктне правило: збігу DOI (β = +3,0)
> самого по собі достатньо для автоматичного злиття, тоді як конфлікт DOI (β = −5,0) не долає навіть
> максимально можлива сума всіх текстових ознак (+4,1), тож така пара не потрапляє навіть у смугу
> перевірки (score = 0,289). Емпірично вибір підтверджено розгорткою порогів (рис. 4): F1 досягає
> максимуму саме при θ_match = 0,90 (76,4 %), тоді як при 0,85 точність падає до 56,6 %, а при 0,95
> зростає до 98,1 % ціною втрати повноти й нижчої F1 (75,9 %). Поріг θ_review визначає не якість, а
> обсяг ручної роботи: при 0,70 у смугу HITL потрапляє 54,0 пари на дослідника проти 86,1 при 0,60
> та 1,6 при 0,85, коли механізм перевірки фактично вимикається.

### Підпис до нового рисунка

> Рис. 4. Обґрунтування порогів зіставлення: ліворуч — точність, повнота та F1 залежно від порогу
> автоматичного злиття θ_match (максимум F1 — при 0,90); праворуч — навантаження смуги ручної
> перевірки залежно від θ_review за фіксованого θ_match = 0,90
