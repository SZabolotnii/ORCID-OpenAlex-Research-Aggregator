# Рецензування ІТЗН — раунд 1 (подання 6755)

Матеріали редакційного рішення та плану доопрацювання статті
«Генеративний штучний інтелект та автономні агенти в управлінні науковою діяльністю закладів вищої освіти».

| Файл | Зміст |
|---|---|
| `00_editor-decision.md` | Рішення й вимоги редакції, файли подання в OJS, формат відповіді |
| `01_reviewer-1.md` | Рецензія 1 дослівно + нумерація зауважень R1-1…R1-8 |
| `02_reviewer-2.md` | Рецензія 2 дослівно + нумерація зауважень R2-1…R2-7 |
| `03_response-plan.md` | План реагування: рішення, дії по кожному зауваженню, порядок робіт, ризики |
| `04_response-tables.md` | Заготовка файлу «Зауваження — Виконано/не виконано» для редакції |
| `05_sensitivity-results.md` | Етап 1: результати експериментів чутливості (θ, β, модель ручної праці) + готові фрагменти для рукопису |
| `06_figures-and-volume.md` | Етап 2: нові рисунки (конвеєр ER, понятійна схема), план перенумерації, бюджет обсягу за вимогами ІТЗН |

| `08_revision-built.md` | Етап 3: зібрані файли подання, контрольні показники, що лишилося зробити |

**Рішення:** необхідні виправлення. Рецензент 1 — з повторним рецензуванням.
**Стан:** зауваження зафіксовано, план складено, стратегічні рішення ухвалено (2026-09-04); правки не розпочато.

**Ухвалені рішення** (§2 плану):
- **A2** — пілот на реальних даних ЗВО не проводимо; агентний шар подаємо як концепт із задекларованою майбутньою інтеграцією;
- **B** — назву статті залишаємо без змін; коригуємо анотацію, мету й висновки;
- **C** — міні-оцінювання агента виконуємо, але результати публікуємо у відкритому репозиторії, а не в статті.

**Файли для подання зібрано:** `paper/ITLT_TRACE_ITZN_revision1.docx` (стаття з правками, виділеними
синім) і `paper/ITLT_6755_response_tables.docx` (таблиці відповідей на кожного рецензента).

**Наступний крок:** коректорська вичитка (R1-5), візуальна перевірка верстки у Word, заповнення
номерів сторінок у таблицях відповідей — перелік у `08_revision-built.md`.
Закрито: E-1; Етап 1 (експерименти чутливості); Етап 2 (рисунки); Етап 3 (правки внесено).

Вихідний рукопис: `paper/ITLT_TRACE_ITZN_final_summision.docx` (текстовий дамп джерел для правок
можна відтворити конвертацією docx).
